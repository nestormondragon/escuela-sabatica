# English content edition

These files are the English authored edition of the Q3 2026 lesson drafts.
They preserve the Spanish edition's lesson ids, route slugs, stage ids, slot
ids, station ids, module types, option ids, tag values, and storage keys.
That identity contract lets a reader change languages without creating a
second journey or losing saved answers.

The devotional prose is an English adaptation of the app's Spanish authored
copy, not a reproduction of the quarterly PDF. Scripture references preserve
the same biblical locations as the Spanish edition. Scripture wording in this
edition is a faithful working translation of the Spanish draft unless a source
is named in the text; the app does not attribute it to a published English
Bible version.

Edit these JSON drafts, then run `npm run build:lessons`. Never hand-edit the
generated modules under `src/content/en/`.
